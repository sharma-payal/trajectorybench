# Synthetic encounter fixtures

This directory contains three fictional JSONL records created solely to test TrajectoryBench.

## Provenance

- Source: authored for this repository
- Real patients: none
- External datasets: none
- Web-scraped clinical text: none
- Protected health information: none
- Permission or data-use agreement required: none

The records are intentionally minimal and do not represent clinical prevalence, care standards, demographic distributions, or model performance. Any resemblance to a real person or encounter is coincidental.

See [DATA_PRIVACY.md](../DATA_PRIVACY.md) for the complete public-release policy and audit.
